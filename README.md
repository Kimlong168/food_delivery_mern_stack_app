
# Mern Stack website project

Welcome to the Mern stack website project. This project is set up with React and Vite for fast and efficient development.

## Getting Started

Follow these instructions to get a copy of the project up and running on your local machine.

### Prerequisites

Make sure you have the following installed:

- [Node.js](https://nodejs.org/) (version 16 or higher recommended)
- [npm](https://www.npmjs.com/) (comes with Node.js) or [Yarn](https://classic.yarnpkg.com/) (optional)

### Clone the Repository

Start by cloning the repository to your local machine:

```bash
git clone https://github.com/Kimlong168/food_delivery_mern_stack_app.git
```

### Clone the Repository
Change into the project directory:

```bash
cd food_delivery_mern_stack_app
```

### Install Dependencies
Install the project dependencies using npm

```bash
npm install
```

### Run the Project
To start the development server and see your project in action, use:
```bash
npm run dev
```
